Windows Terminal 설정 연동 (2.0.8.5)

설치 갱신 완료. 실제 앱에서 Windows PowerShell 시작 및 초록색 커서, 설정 글꼴 표시를 확인했습니다.
기존 Windows Terminal 설정 파일은 수정하지 않았습니다.

반영 범위
- Windows Terminal settings.json의 기본 PowerShell 프로필 선택 및 commandline 그대로 사용 (환경 변수 확장)
- PowerShell의 정상 프로필 로딩을 유지하며 임의의 -NoProfile/ExecutionPolicy 옵션을 추가하지 않음
- profiles.defaults와 선택 프로필을 병합. font는 항목별 상속
- 글꼴/크기/굵기, 색 구성표(내장 및 사용자 정의), 개별 색상, 커서 모양·색상, 스크롤 이력, 여백
- 로컬 배경 이미지·투명도·늘이기 방식
- 크기 단위: Windows Terminal의 포인트를 CSS 픽셀로 변환
- 설정 변경은 터미널 패인을 다시 열면 반영
- 작업 폴더는 SpanFinder에서 선택한 폴더를 유지
